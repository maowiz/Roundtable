How Roundtable manages memory

Every AI call starts with a blank memory. For each call the app packs a sealed envelope with only what that step allows. The AI sees the envelope and nothing else.

STEP
✓ IN THE ENVELOPE
✗ NEVER SEEN
STEP 1AnswerEach agent answers alone
✓Your question
✗Other agents' answers✗Any earlier chat
STEP 2ReviewEach agent reviews one other answer
✓Your question✓One other answer as "Answer A-7K2"
✗Who wrote it✗Its own answer✗Other reviews
STEP 3ImproveEach agent fixes its own answer
✓Your question✓Its own answer✓Reviews about it names hidden
✗Other agents' answers✗Who reviewed it
STEP 4Final answerOne writer combines everything
✓Your question✓All improved answers shuffled, names hidden
✗The reviews✗Who wrote what
🧠
Fresh memory every callNothing is carried over between calls
🎭
Names become codesNo AI knows which AI wrote what
📒
Every envelope is savedYou can open any one later and check it
